Once every label is reviewed, run bun evals --update-baseline in a terminal. The stored baseline in evals/baseline.json was measured against the drafts, so the accuracy the eval test checks against is the drafts' number, not yours. Re-baselining makes the check guard the reviewed labels.

You don't need to edit results.md: bun evals prints the "Provisional" note from the count of rows still labelled draft or draft-checked, so it disappears by itself once none remain.
